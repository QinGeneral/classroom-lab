- 挑战模式左盘仍锁定；点击实验页品牌返回首页。
- 教学说明对话框打开与关闭正常，关闭后 `dialog.open` 为 false。
- 首页缩略图完成加载，12 个年级按钮均在 DOM 中；浏览器 warning/error 日志为空。
- 390px 与 320px 首页、实验页均无横向溢出；在 390px 验证年级筛选、空态恢复、进入实验、返回首页。
