# 绿豆天平设计与修复

参考 `design-concept.png`：浅象牙白背景 #f7f8f2、森林绿文字 #244a3d、浅青柠按钮、陶橙左盘和青绿右盘。系统中文字体，标题 44px，正文 16px，数字 52px。桌面为实验台与观察栏 3:1，移动端自然上下排列。主界面文案、组件和顺序按概念图实施。

保留原网页的加减豆子、平衡/左右重反馈、气泡指示、清空和随机机制。教学示意图以 SVG 精确绘制，保证横梁端点、悬线、水平托盘和豆子同步；这是有意采用的代码原生教学图，不是静态生成图片。角度是数量差的限幅教学示意，不代表真实静态天平的力学求解。气泡流向高处。

功能扩展：可隐藏数量，平衡挑战锁定左盘、调整右盘后检查，支持键盘、全屏、帮助、减少动画。每侧上限 30 颗，所有豆子显示，数字不会为负或 NaN。不使用外部字体、CDN、统计或网络服务，可双击 HTML 离线教学。

原版已确认问题：Unicode 减号交给 parseInt 得到 NaN；HTML 豆子没有按 SVG 横梁的旋转端点定位；只容纳一排的截断逻辑漏画；缩放后像素与 viewBox 混用；大数量的豆子倾角未限幅；气泡说明与实际方向冲突；两侧各 4 按钮在窄屏溢出；缺少挑战目标和答案验证。

## 图像生成来源

概念图采用内置 Image Gen 工具生成，输出保存为 `docs/design-concept.png`。实际网页不引用该位图。提示词要点：完整中文课堂实验工具界面，1512×1048 参考尺寸，品牌“绿豆天平 / 课堂实验室”，标题“让平衡，看得见”；象牙白、森林绿、青柠、陶橙和青绿；左侧矢量天平、五颗对五颗、四个加减按钮，右侧观察比较、三条规则和思考题，双模式与全屏帮助。所有文字和控件保留原生 HTML，图形可交互、可缩放，无营销模块、人物或照片。

## 用户指定气泡组件

后续按用户红框参考，将气泡管恢复为鲜绿色、有左中右三格和白色气泡的独立组件，并始终置于最前层。气泡居中表示平衡；偏左对应左高右低，偏右对应右高左低。组件、横梁在每帧保持同角度。此项以用户指定参考覆盖初始概念图中较小的浅色指示器。

## 多年级目录首页

新增 `home-concept.png` 为首页视觉参考，覆盖小学、初中、高中。保持现有象牙白、森林绿和青柠风格，三块年级导航后连接可搜索、可筛选的真实实验目录。现有实验迁至独立路径，并加返回首页的入口。实际图形仍使用代码原生 SVG，以保留用户指定的绿色气泡管和正确的悬挂结构。
